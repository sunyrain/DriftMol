# Drifting Faithfulness Experiment Plan

Updated: 2026-05-15 UTC

This plan addresses a specific reviewer risk: the paper should demonstrate that
DriftingMol faithfully implements the original Drifting Models recipe before
arguing for molecule-specific decoder-coupled drift.

## Reviewer Question

The likely criticism is:

> Is DriftingMol really a faithful reproduction of Drifting Models, or is it a
> different latent heuristic that borrows the name?

The response should not rely only on prose. It should provide:

1. an equation-to-code audit,
2. a strict latent-MAE feature-space reproduction,
3. destructive anti-symmetry ablations matching the original paper's logic,
4. positive/negative sample allocation experiments analogous to the original
   Table 2,
5. feature-quality controls analogous to the original Table 3,
6. and clear separation between faithful reproduction and the proposed
   decoder-coupled extension.

## What Is Already Covered

### Algorithm 2 Code Path

The current implementation in `src/drifting/drift_latent_phi.py` contains
`compute_drift_field_paper`, which implements the original Algorithm 2 design:

- L2 distance, not squared distance.
- positive and generated-negative logits concatenated before normalization.
- row softmax and column softmax.
- geometric mean `sqrt(row * col)`.
- cross-multiplication between positive and negative masses.
- generated samples as negative samples.
- `V = V+ - V-`.

The audit script `scripts/audit_drifting_faithfulness.py` compares this
implementation against a direct local transcription of Algorithm 2 on synthetic
tensors and writes:

- `results/drifting_faithfulness_status.json`
- `results/drifting_faithfulness_audit.md`

Current audit status is `PASS`: the strict core and allocation sweeps are
complete, and the conservative audit verifies the full 10-run
reviewer-faithful manifest.

### Existing Feature-Space Results

The existing C1-C5 experiments already show that frozen latent feature
extractors work but underperform decoder coupling:

| Variant | Meaning | Current QED rho | Current uniqueness |
|---|---|---:|---:|
| C1 | plain latent-MAE phi | 0.297 | 96.3% |
| C2 | property-aware latent-MAE phi | 0.329 | 94.8% |
| C3 | latent-MAE + z | 0.312 | 97.2% |
| C4 | latent-MAE + decoder | 0.281 | 98.8% |
| C5 | property-aware latent-MAE + decoder | 0.296 | 97.8% |

These results are useful but not fully strict reproductions, because they use
some molecule-specific stabilizers such as the current positive sampler,
fixed drift lambdas, and z-diversity.

### Destructive Anti-Symmetry Ablations

The running destructive-ablation group mirrors the original paper's
anti-symmetry table:

- attraction-only,
- repulsion-only,
- overweighted attraction,
- overweighted repulsion,
- y-only normalization,
- no cross-multiplication,
- no normalization.

This directly tests whether the balanced `V+ - V-` field is necessary in the
molecular latent setting.

## Core Faithfulness Runs

All core runs use the molecular analogue of the original Drifting ablation
default:

- latent generator output,
- QED quantile bins as class labels,
- `N_c=64`, `N_neg=64`, `N_pos=64`, effective batch `4096`,
- temperatures `{0.02, 0.05, 0.2}`,
- Appendix-A.6 feature-distance and drift normalization,
- training-time CFG with alpha sampled from `[1,4]` as `alpha^-3`,
- generated samples as negatives,
- no molecule-specific z-diversity term,
- 100 epochs.

| Run | Purpose |
|---|---|
| `rf_FD_STRICT_PLAIN_PHI_QED_s42` | strict latent-MAE phi reproduction, closest to the original recipe |
| `rf_FD_STRICT_PROP_PHI_QED_s42` | feature-quality check, analogous to latent-MAE plus classifier/property fine-tuning |
| `rf_FD_STRICT_RANDOM_PHI_QED_s42` | random feature control, tests whether feature semantics matter |
| `rf_FD_STRICT_ZSPACE_QED_s42` | no-feature z-space control, tests the need for a learned phi space |

Expected paper use:

- If strict plain-phi works but decoder coupling is better, the paper can state
  that Drifting was faithfully reproduced and then improved for molecules.
- If strict plain-phi is weak, the paper can state that a direct faithful port
  is insufficient and decoder coupling is the molecular adaptation that closes
  the gap.
- If random phi or z-space performs similarly to plain phi, the feature-space
  mechanism claim should be weakened.

Observed strict-core result:

- All four core rows have final metrics.
- The strongest strict-core row is z-space drift at best alpha `5.0` with QED
  Spearman rho `0.127`, uniqueness `97.8%`, MAE `0.221`, and slope `0.169`.
- Plain and property-aware phi are complete but weaker (`rho=0.055` and
  `0.105`). Random phi is similar to z-space (`rho=0.122`).
- Therefore the supplement should present these rows as faithful reproduction
  and boundary evidence, not as a strong feature-extractor superiority claim.

Negative allocation, fixed effective batch `4096`:

| Run | Nc | Nneg | Npos |
|---|---:|---:|---:|
| `rf_FD_ALLOC_NEG16_QED_s42` | 256 | 16 | 16 |
| `rf_FD_ALLOC_NEG32_QED_s42` | 128 | 32 | 32 |
| `rf_FD_ALLOC_POS64_QED_s42` | 64 | 64 | 64 |

Expected paper use:

- If larger positive/negative sample sets improve control or diversity, the
  result aligns with the original Drifting sample-estimation story.
- If allocation has little effect, the paper should say the molecular setting
  is less sample-estimation-limited than ImageNet and more representation-limited.

Observed allocation result:

- `Npos=1` is complete and weak: best alpha `3.0`, QED Spearman rho `0.028`,
  uniqueness `68.7%`, MAE `0.251`, and slope `0.035`.
- This is a useful low-positive negative control: diversity partially recovers,
  but target tracking remains collapsed around QED `0.50`.
- `Npos=16`, `Npos=32`, `Npos=64`, `Nneg=16`, and `Nneg=32` are complete.
  Larger positive/negative allocation improves diversity but does not restore
  strong QED target tracking; the best allocation rows remain around
  QED rho `0.076`.
